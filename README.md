# 食物热量小程序一期 · 部署与体验版步骤

## 一、目录
- server/：后端中转（Express + 百炼 qwen-vl-max + 营养表对表）
- miniapp/：微信小程序（原生）

## 二、后端本地跑通（开发/预览用）
1. `cd server && npm install`
2. 复制 `.env.example` 为 `.env`，填入你自己保管的 `DASHSCOPE_API_KEY`（不要在聊天里发 key）。
3. `npm start`，访问 `http://localhost:3000/health` 应返回 `{"ok":true,"model":"qwen-vl-max"}`。
4. 用 curl 或 Postman 测：`POST /api/analyze`，form-data 字段名 `images`，传一张菜品图，应返回 dishes/total/advice。

## 三、开发版真机预览（最快）
1. 微信开发者工具打开 `miniapp/`，AppID 填 `wxc3b95e02a5ef8400`。
2. 详情 → 本地设置 → 勾选“不校验合法域名”（仅开发/预览有效）。
3. 首页 `index.js` 里 `apiBase` 默认 `http://localhost:3000`。真机要访问电脑上的服务，需同一局域网并把 `localhost` 换成电脑局域网 IP（如 `http://192.168.1.8:3000`），或内网穿透（cpolar/ngrok）拿一个 https 地址。
4. 点“预览”生成二维码，真机扫码即可测拍照上传全流程（这一步就是“真机实测”，必须做）。

## 七、欢迎参与（提建议 / 优化代码）

这个项目公开，欢迎大家参与优化。

- **提问题或建议**：直接在仓库开 Issue，说清遇到的问题或想改的地方。
- **改代码**：先 fork 仓库，改完提 Pull Request（PR），写清改了什么、为什么改。PR 由管理员审核，通过后合并。
- **动手前打个招呼**：先在 Issue 里说一声要改什么，避免和别人改重了。
- **不要提交密钥**：`.env` 已被忽略，后端 key 各自保管，别放进代码里。本地跑后端需要自己去阿里云百炼开通 key。
- **合并不等于上线**：线上体验版跑的是云托管里部署好的版本，合并后需要重新部署才生效。

# 部署到腾讯云轻量服务器（含备案）

## 一、老钟在腾讯云要做的四步

1. **买服务器**：轻量应用服务器 / 2 核 2G / 4M / Ubuntu 22.04 或 24.04 / 地域上海或广州。
   买完记录：公网 IP、root 密码。
2. **买域名**：同账号，`.com` 或 `.cn`，做完实名认证（身份证）。
3. **备案（网站）**：腾讯云控制台 → 备案 → 新增网站备案 → 个人主体，用这台服务器申请。
   网站名称写工具类（例「美食热量记录工具」），不要出现商城、平台、交易类字样。
   周期：7–20 个工作日。
4. **小程序备案**：微信公众平台 → 设置 → 基本设置 → 小程序备案，等网站备案下来后再提，约 1–2 周。

> 备案期间域名无法解析到国内机房（会被拦），所以先做下面第二步的技术联调。

## 二、服务器就绪后（我来执行）

```bash
# 上传本目录到服务器，或直接 git 拉（仓库里已有 deploy/）
bash deploy/setup.sh <域名> <DASHSCOPE_API_KEY>
```

setup.sh 做完：Node 22 + 代码拉到 /opt/food-calorie + 环境变量 /etc/food-calorie.env（600）+ systemd 常驻 + Nginx 反代（20m 上传上限）+ certbot 免费证书自动续期 + 健康检查。

验证：

```bash
curl http://<公网IP>/health        # 备案前用 IP 直连，应返回 {"ok":true,"model":"qwen3-vl-plus"}
curl https://<域名>/health         # 备案+证书后
```

## 三、备案等待期的联调方案（不干等）

1. 服务器 80 端口对公网开放（腾讯云防火墙放行 80/443），Nginx 用 IP 直接跑 HTTP。
2. 小程序：开发者工具 → 详情 → 本地设置 → 勾选「不校验合法域名」；真机用「真机调试」模式。
3. 首页「服务端地址」填 `http://<公网IP>`。
4. 跑通拍照 → 分析 → 结果页全链路，把 `DASHSCOPE_API_KEY` 与模型权限问题在这一步暴露出来。

## 四、备案通过后的切换清单

1. `certbot --nginx -d <域名> --redirect` 拿证书（setup.sh 里已含，失败可重跑）。
2. 微信公众平台 → 开发 → 开发设置 → 服务器域名 → request 合法域名填 `https://<域名>`。
3. 小程序首页「服务端地址」留空（回到默认）或填正式域名。
4. 生成体验版二维码，真机全流程再验一遍。
5. 小程序备案通过后才能提交审核发布。

## 五、注意事项

- 免费证书 90 天，certbot 自带定时续期（`systemctl list-timers | grep certbot` 可查）。
- 图片上传走 multipart，Nginx 已放 20m；小程序端 `wx.chooseMedia` 有压缩，实际单图多在 1–3MB。
- 服务日志：`journalctl -u food-calorie -f`。
- 若百炼模型未开通，`/api/analyze` 会返 500 并写明原因，属预期。
